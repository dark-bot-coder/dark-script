# Plano — [[1.2.1-script-vod-report-faststart]]

- **Etapa:** 002_planning · **Responsável:** agent planejador

## Objetivo e resultado esperado

- **Objetivo:** criar o primeiro script de vod-scripts/: ler a env `SCAN_VOD_FOLDER`, varrer `.mp4`/`.mkv` da pasta e de suas subpastas diretas, detectar os arquivos sem a flag faststart (índice no início — causa da falha em TVs LG) e gravar um relatório Markdown em `vod-scripts/reports/` com timestamp no nome. Somente diagnóstico — nenhum arquivo de vídeo é alterado.
- **Resultado observável:** rodando o script com a env definida, nasce `reports/faststart-report-YYYYMMDDHHMM.md` com cabeçalho, totais e a lista dos faltosos (e erros de leitura à parte); logs em pt-BR no terminal.

## Estratégia

Script Python único em stdlib (sem pacotes pip) mais `ffprobe` como dependência externa — resolve o RECON da epoch: **detecção via trace de boxes do ffprobe lendo apenas o cabeçalho** (`ffprobe -v trace -read_intervals 0%+#1`), sem reprocessar o arquivo inteiro. Alternativas consideradas: (a) parsing manual de boxes MP4 em bytes — rápido e sem dependência, mas não cobre MKV (EBML) sem esforço desproporcional; (b) `ffprobe -show_format/-show_streams` — não expõe a posição do moov. Escolhido o trace de boxes: um único mecanismo para os dois formatos, lendo só o head. Critério: **MP4** — box `moov` deve aparecer antes de `mdat` na ordem dos top-level boxes do trace; **MKV** — análogo streaming-friendly: elemento `Cues` (índice) antes do primeiro `Cluster`. Falha do ffprobe ou box ausente → o arquivo vai para a lista de erros, não para a de faltosos. `ffprobe` ausente no ambiente → erro claro e saída não-zero logo no início.

Decisões operacionais: extensões `.mp4`/`.mkv` **case-insensitive**; varredura da pasta + **subpastas diretas apenas** (1 nível, nunca recursivo além disso). Env ausente/vazia ou pasta inexistente/não-legível → mensagem clara em pt-BR e exit code 2. **Exit code 0 mesmo com faltosos** — o produto é o relatório; achados não são falha de execução (facilita cron e inspeção manual); não-zero só em falha operacional. Nenhuma dependência pip → **não criar requirements.txt** (decisão durável da 1.1.1; setup_venv.sh já trata a ausência). README de vod-scripts ganha o script na seção Scripts com uma linha de uso; `.env.example` já prevê `SCAN_VOD_FOLDER` — sem alteração.

## Riscos e condições de aborto

- **Risco:** saída do `-v trace` variar entre versões do ffprobe e quebrar o parsing — mitigação: fixtures reais no critério 1 exercitam o parsing contra o ffprobe do ambiente; regex tolerante às linhas de box.
- **Abortar se:** ffprobe/ffmpeg ausentes ou incompatíveis no ambiente de execução — sinalizar `blocked: true` com a saída de `which ffprobe ffmpeg`.
