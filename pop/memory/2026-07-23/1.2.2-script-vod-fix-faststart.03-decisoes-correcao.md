# Decisões sobre correção e integração

Definido que correção de MP4 usa `ffmpeg -c copy -movflags +faststart` e MKV usa `mkvmerge -o`. Substituição atômica na mesma pasta preserva permissões via `shutil.copymode`. Modo `--yes` não gera backup. `mkvmerge` é verificado lazy, não como prerequisite de startup. Merge do commit `123a857` foi direto em main.
