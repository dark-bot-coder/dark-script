# Detecção de faststart para MP4 e MKV

Detecção MP4 via trace do ffprobe: verifica se `moov` aparece antes de `mdat` no head do arquivo. Detecção MKV por parsing stdlib dos cabeçalhos EBML top-level: considera sem faststart quando `Cues` aparece após o primeiro `Cluster`. Sem dependências pip; `requirements.txt` permanece omitido.
